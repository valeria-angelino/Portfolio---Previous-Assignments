# Portfolio: Previous Projects

This portfolio includes some of the work I have done over the last few years related to data analysis.

This guide includes the name of the project, the date it was completed, a brief description and the name of the code file respectively.




### Survival Chances in the RMS Titanic Wreck

**Date:** August 2025

**Description:** This project follows EDA, and uses a logistic regression model to find whether there were any key factors that influenced survival during the RMS Titanic wreck. 

**Code File:** Titanic_R_code.r





### Endometriosis Analysis

**Date:** June 2025

**Description:** Using a synthetic dataset, this project aims to answer four research questions regarding endometriosis using a statistical analyses: sample t-test, correlation, one-way ANOVA, chi-squared test.

**Code File:** Endometriosis_Code.R





### Regional Economic Disparities in Denmark

**Date:** March 2025

**Description:** Using STATA to uncover regional economic disparities in Denmark across time aiming to find when did the regional divergence began and wheter patterns show convergence.

**Code File:** Regional_Disparities_code.txt





### Bsc Thesis

**Date:** December 2024

**Description:** Thesis aims to investigate the underrepresentation of women in the Swedish Games Industry from 2006 to 2020. Using a mixed-methods approach, it explores the relationship between education, occupational segregation, and overall underrepresentation of women in the workforce.

**Code File:** Bsc_Thesis_code.do
