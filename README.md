# Portfolio: Previous-Assignments


This repository contains a selection of data analysis projects completed between 2024 and 2025. Each project includes a brief description, completion date, and the corresponding code file.



### Survival Chances in the RMS Titanic Wreck

**Date:** August 2025

**Description:** This project follows EDA, and uses a logistic regression model to find whether there were any key factors that influenced survival during the RMS Titanic wreck. 

**Code File:** Titanic_R_code.r





### Endometriosis Analysis

**Date:** June 2025

**Description:** Using a synthetic dataset, this project aims to answer four research questions regarding endometriosis using several statistical analyses, including a one-sample t-test, correlation analysis, one-way ANOVA, and a chi-squared test.

**Code File:** Endometriosis_Code.R





### Regional Economic Disparities in Denmark

**Date:** March 2025

**Description:** Using Stata to examine regional economic disparities in Denmark over time, this project investigates when regional divergence began and whether subsequent patterns indicate convergence.

**Code File:** Regional_Disparities_code.txt





### Bsc Thesis

**Date:** December 2024

**Description:** Thesis aims to investigate the underrepresentation of women in the Swedish Games Industry from 2006 to 2020. Using a mixed-methods approach, it explores the relationship between education, occupational segregation, and overall underrepresentation of women in the workforce.

**Code File:** Bsc_Thesis_code.do
